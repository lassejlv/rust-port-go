# Restricted-names validation evidence

Completed on Linux/amd64 using Go 1.23.12 and Go 1.27.3. The reference compiler
was exactly `rustc 1.99.1 (58cf8f9c3 2026-10-13)`, standard-library Unicode
17.0.0. Source and dependency pins, all generator/wrapper hashes, and fixture
hashes are recorded in `manifest.json`; reproduction and API decisions are in
`PORT.md`.

Results:

- Complete unchanged pinned Rust source compiled with all six exact locked
  registry packages. Original inline test: **1 passed**, preserving its 18
  assertions; the Go mirror passes in the same case order.
- Original-source differential corpus: **32,779 requests passed** across all
  six validators and two sanitizers. Validator results compare success/error,
  complete Display, complete derived Debug, and transparent Error source.
  Sanitizer results compare exact UTF-8 bytes, including NUL placeholders.
- Streaming formatter corpus: **31,664 scripts passed**, comparing **659,866
  attempted C/S writes** and **28,016 failing scripts**. All four error variants,
  19 source format patterns, empty/Unicode/NUL/control/multiline payloads,
  default/overridden `write_char`, every discovered failure position, accepted
  byte prefixes and mutable formatter reuse/state match original Rust.
- Unicode domain: **1,112,064 scalar values passed**, comparing locked
  XID_Start/XID_Continue, standard alphanumeric, ASCII-only decimal digit,
  lowercase mappings, and first/following Rust Debug-escaping predicates.
  Every surrogate slot is explicitly checked as a non-scalar. Rust-side
  assertions also check each special escape and character/string Debug mapping.
- Focused regressions cover Unicode lowercase reservations (`pacKage`), final
  sigma and dotted-I expansion, empty profiles, initial Arabic versus ASCII
  digit diagnostics, invalid prefixes/components, arbitrary placeholders,
  exact error Debug, source-chain transparency, and Rust UTF-8/scalar
  preconditions.
- Go 1.23.12 full package/tool/shared-util tests and vet passed.
- Go race checks passed for the complete new package and generation tool.
- After the streaming update, Go 1.23.12 package/tool race checks passed
  (7.019s/1.268s), vet passed, and bare-PATH live `-check` regenerated all
  validation/scalar/formatter observations against Go 1.27.3 evidence without
  changing compressed bytes or generation metadata.
- Fuzzing passed **59,273 executions** in approximately 11 seconds with two
  workers, exercising all validators and valid-placeholder sanitization.
- Live regeneration under Go 1.23.12 with bare `rustc` and `cargo` selected
  through PATH passed `-check` against evidence generated by Go 1.27.3, with
  compressed bytes and generation provenance preserved.
- Tool unit tests passed for flag/environment/PATH precedence; explicit empty
  and missing selections; archive checksum and expanded-source tampering;
  missing selected dependencies; deterministic request generation; and
  preserving a valid gzip stream with a different level/header while rejecting
  truncated, CRC-corrupt, changed, or absent streams in check mode.
- Nine invalid CLI/environment selections were independently invoked against
  the built tool: empty Rust/Cargo/source/home/root selections, a missing Rust
  path, an incompatible executable, an explicitly empty Rust environment
  selection, and an unexpected positional argument. Every invocation failed
  with a diagnostic, and hashes of all retained evidence remained unchanged.

Commands used for the principal checks:

```sh
go test ./port/cargo/crates/cargo-util-schemas/src \
  ./tools/port-cargo-restricted-names ./port/cargo/src/util -count=1
go vet ./port/cargo/crates/cargo-util-schemas/src \
  ./tools/port-cargo-restricted-names ./port/cargo/src/util
go test -race ./port/cargo/crates/cargo-util-schemas/src \
  ./tools/port-cargo-restricted-names -count=1
go test ./port/cargo/crates/cargo-util-schemas/src -run '^$' \
  -fuzz '^FuzzRestrictedNameValidation$' -fuzztime=10s -parallel=2
FERRUGO_RUSTC=rustc FERRUGO_CARGO=cargo \
  go run ./tools/port-cargo-restricted-names -check
```

These results validate the entire pinned restricted-names source file under
the declared dependency/runtime profile. They do not establish full Cargo or
Rust compiler completion, and the bootstrap manifest parser's accepted-name
profile was not expanded by this component port.
