# Original rustc_lexer oracle

This harness compiles the **unmodified complete** upstream
[`compiler/rustc_lexer/src/lib.rs`](https://github.com/rust-lang/rust/blob/2d20b42b883dcfc014f3c2c56081eeb6091c2179/compiler/rustc_lexer/src/lib.rs)
at Rust revision `2d20b42b883dcfc014f3c2c56081eeb6091c2179` with a stable Rust
compiler and edition 2024. It also runs all 17 original tests from the pinned
`src/tests.rs`. The Go port is compared directly with this compiled original;
the bootstrap parser/compiler is not an oracle or a dependency.

The Go test checks the source checkout revision and these Git blob hashes before
compilation:

| Source | Git blob SHA-1 |
| --- | --- |
| `compiler/rustc_lexer/src/lib.rs` | `0aa57e75889fa2d81deb1ec8bf5480b1c930fff1` |
| `compiler/rustc_lexer/src/tests.rs` | `a7357ba38c8e4484da814ef3c22bf33b75bdbeb2` |

`Cargo.toml` and `Cargo.lock` pin the exact dependencies resolved by that revision's
root lockfile: memchr 2.8.0, unicode-ident 1.0.24, unicode-properties 0.1.4
with only its emoji feature, expect-test 1.5.1, dissimilar 1.0.10, and once_cell
1.21.3. Checksums are retained. Rust source licenses are in `port/rust/`.

## Go-only baseline

```sh
go test ./port/rust/compiler/rustc_lexer/src
```

`testdata/oracle_corpus.json` contains 231 input/result pairs generated by the
compiled original using rustc 1.99.1. Ordinary tests use those committed results
and need no Rust, Cargo, Git, dependency cache, or network. The corpus includes
both frontmatter modes, every token variant, malformed literals/comments,
Unicode byte lengths, NUL and CRLF, shebangs, raw delimiter counts around 255,
guarded strings, identifier/whitespace predicates, and cursor state transitions.

## Live comparison with the original

Prepare the pinned source caches and download the locked oracle dependencies
once. These preparation commands use the network:

```sh
python3 tools/port-inventory/inventory.py prepare
export CARGO_HOME="$PWD/.toolchain/port-cargo-home"
export FERRUGO_CARGO="$PWD/.toolchain/rust/bin/cargo"
export FERRUGO_RUSTC="$PWD/.toolchain/rust/bin/rustc"
RUSTC="$FERRUGO_RUSTC" "$FERRUGO_CARGO" fetch --locked \
  --manifest-path tools/port-lexer-oracle/Cargo.toml
```

Then compare without network access:

```sh
FERRUGO_LEXER_ORACLE=1 go test ./port/rust/compiler/rustc_lexer/src \
  -run '^TestOriginalLexerOracle$' -count=1 -v
```

The test creates a standalone temporary Cargo crate, adds a module declaration
pointing to the verified original source, and appends this directory's driver.
The source itself stays untouched. Importing it as a module also permits testing
its original `pub(crate)` cursor helpers. Original tests and the oracle binary
build with `--locked --offline`; the upstream compiler workspace is never built.
The tracked manifest and driver are sufficient for `cargo fetch`; compiling and
testing require the temporary shim generated by the Go test.

The optional environment variables `FERRUGO_CARGO` and `FERRUGO_RUSTC` select
original executables, including bare `cargo`/`rustc` names resolved through
`PATH`. Defaults are `.toolchain/rust/bin/cargo` and
`.toolchain/rust/bin/rustc`. `FERRUGO_RUST_SOURCE` selects the pinned Rust checkout,
defaulting to `.toolchain/upstream-rust`. `CARGO_HOME` is respected and otherwise
defaults to `.toolchain/port-cargo-home`. Relative paths resolve from the
repository root, including executable overrides containing a path separator. Empty,
missing, incompatible, or incorrectly pinned selections fail; the test does not
substitute another implementation. The opt-in flag must equal `1` when set.

Each run compares:

- All 231 committed requests and their original-generated results.
- 6000 deterministic valid-UTF-8 fragment/scalar inputs, plus sampled shebang,
  Unicode predicate, and cursor operations.
- 1024 raw-string validations, 1024 guarded-string parses, and 1024 frontmatter
  cases, including malformed delimiters and recovery paths.
- Every currently hydrated `.rs` file in the Rust source cache, Cargo source
  cache, and Ferrugo repository, excluding Git/build/cache directories. Files
  are checked as document slices and as complete documents after shebang
  removal. Sparse caches contain only their checked-out files; this does not
  claim that all upstream source blobs were hydrated. Non-UTF-8 files are counted
  and skipped because the original API requires `&str`.

The random seed is `0x2d20b42b883dcfc0`; its xorshift sequence is defined in the
test. Failures show the exact case name, input prefix, operation, and first
differing output line. Tokens compare Rust's derived `Debug` output, including
all metadata and byte lengths. Raw-string errors compare numeric Unicode scalar
values and structured counts/offsets, avoiding diagnostic-character escaping
differences. Cursor tests compare peeks, previous scalar, remaining bytes, EOF,
position/reset, bump/byte advances, predicate scanning, and token advances. The
oracle uses debug assertions, as required by upstream's debug-only `prev` field.

The first complete run matched 548 hydrated source files (4,704,893 bytes), all
17 original tests, and every generated case. Source counts change as caches and
fixtures grow; the live test logs the current counts.

## Refreshing committed results

After reviewing input changes, regenerate their results from the verified
original explicitly:

```sh
FERRUGO_LEXER_ORACLE=1 FERRUGO_LEXER_UPDATE=1 \
  go test ./port/rust/compiler/rustc_lexer/src \
  -run '^TestOriginalLexerOracle$' -count=1
go test ./port/rust/compiler/rustc_lexer/src
```

Golden updates still require Go/original parity. No production binary invokes
this Rust oracle; this harness provides validation for the source-file port.
